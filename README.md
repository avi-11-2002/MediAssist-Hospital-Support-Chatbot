## 📌 About the Project

MediAssist AI is a beginner-level machine learning project that uses a chatbot interface to collect basic information about a user's symptoms and recommend a suitable hospital department.

The project combines text-based symptom information with basic structured information such as age, gender, duration of symptoms, and severity.

> ⚠️ **Disclaimer:** This project is for educational purposes only. The department recommendation is generated by a machine-learning model trained on the project dataset and may be inaccurate. It should not be considered a medical diagnosis or a replacement for professional medical advice.

## ✨ Features

- Simple chatbot-based interface
- Collects user's symptoms
- Collects age, gender, duration, and symptom severity
- Selectable buttons for gender, duration, and severity
- Uses TF-IDF to process symptom text
- Combines text features with structured features
- Uses a trained machine-learning model for prediction
- Displays a recommended hospital department
- Allows the user to start a new consultation
- Includes a medical disclaimer
